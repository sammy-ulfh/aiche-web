## 5. Desviaciones respecto al plan

- El plan original proponía extraer **también** `SponsorTierCards` mini para unificar `SponsorTeaser` + `SponsorHero`. **No se hizo**: las diferencias de padding y tamaño de fuente son intencionales (la home resume, `/patrocinios` presenta); unificarlas perdería la jerarquía.
